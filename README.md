# Climate Status App

A weather lookup app that shows current weather conditions based on your location, built with JavaScript and the OpenWeatherMap API.

## Features
- Detects user location and fetches current weather automatically
- Displays temperature and weather conditions

## Tech Stack
JavaScript, OpenWeatherMap API

## Installation
```bash
git clone https://github.com/sinamahboub/Climate-status-app.git
cd Climate-status-app
```
Open `index.html` in your browser.
